# pairwise-webhook-verify

支付回调一接第三方，签名校验就只做了“有没有”：HMAC 用解析后的 JSON 重新序列化再算，字段顺序一变就验不过，验不过时又走“兼容模式”直接放行；时间戳不校验，重放昨天的回调还能发货；签名比较用字符串 ==；多签名头只取第一个，轮换密钥期间旧密钥永久有效；签名头解析按逗号切分，带逗号的签名值被截断；请求体大小不限制，HMAC 计算前先读进内存；URL 编码和原始 body 不一致；算法字段由请求指定，none 也能过；空密钥时直接返回 true；重放缓存只按事件 ID，伪造 ID 就能重复；时间戳允许未来 1 小时；重试回调没有幂等键；失败响应泄露期望签名；密钥硬编码在代码里；验签失败后仍会更新订单状态。security/webhook_verify.py 是核心，tests/test_webhook_verify.py 15个红。要修的是：原始 body 验签；时间戳窗口；常量时间比较；多签名逐个验；密钥轮换；签名头解析；请求体上限；编码一致；固定算法；空密钥拒绝；事件 ID+时间戳重放缓存；未来时间限制；幂等键；错误脱敏；验签通过前不改状态。

## 运行

```bash
python -m pytest tests -q
```
